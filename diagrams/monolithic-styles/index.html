Monolithic Architecture Styles

One deployable, organized four ways. The Clean Architecture and Vertical Slice diagrams follow the samples/clean-architecture and samples/vertical-slice samples, which build the same TicketTide API in each style.

DiagramWhat it shows
Layered (N-tier)Layers call down to the database; relaxed layering and the architecture sinkhole
Clean ArchitectureEvery project references Core; at runtime, calls go out through Core's interfaces
Vertical Slice ArchitectureOne slice per feature over a small shared base; a new feature is a new slice
Class Libraries OnlyA monolith's modules reference each other freely and form cycles
Modules and ContractsA modular monolith: modules depend only on each other's contracts
